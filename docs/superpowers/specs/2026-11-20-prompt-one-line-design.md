# 프롬프트 칸 한 줄로 정리 + 홈 화면에서 인원 바꾸기 (짧은 설계)

## 왜
- 홈 화면에서 바로 클로드 수를 바꾸고 싶다. 지금은 왼쪽 메뉴 → 에이전트 관리의 −/+ 에서만 된다.
- 프롬프트 칸이 복잡하다: '보낼 곳'에 일꾼마다 칩이 붙어 5명만 돼도 두 줄로 넘치고, '모두에게' 설정 네 칸이 늘 펼쳐져 있다.

## 목표 / 하지 않을 것
- 목표: 글 칸 아래를 한 줄로. 인원 −/+ 는 그 줄에 늘 보이게. 8명이 돼도 길어지지 않게.
- 하지 않음: 보내는 방식(자동 배정·전체·팀장에게·골라서)이나 설정 값 자체는 바꾸지 않는다. 에이전트 관리 화면의 −/+ 도 그대로 둔다.
- 실패로 볼 것: 지금 고른 보낼 곳이나 돈이 드는 빠른 모드(↯)가 켜져 있는지를 접혀서 모르게 되는 것.

## 고른 방법 (Approaches)
1. 보낼 곳만 줄이기 — 두 줄 남음, 설정 늘 보임.
2. 설정만 접기 — 일꾼 칩이 남아 많아지면 다시 길어짐.
3. **한 줄로 (사용자가 고름)** — 가장 깔끔. 대신 특정 일꾼 고르기·설정 바꾸기는 한 번 더 누른다.

## 모양
```
> 에이전트에게 시킬 일을 적어 주세요
- - - - - - - - - - - - - - - - - - - - - - - - - - - - - -
[● 자동 배정 ▾]  인원 [−] 5명 [+]  [⚙ 설정 ▾]        📎 [보내기 Enter]
```
- **보낼 곳 버튼**: 지금 고른 것을 글자로 보여 준다 — `자동 배정` / `전체 5명` / `팀장에게` / `클로드 1` / `클로드 1·클로드 3`(두 명) / `클로드 1 외 2명`(세 명 이상). 누르면 메뉴: 자동 배정, 전체 N명, 팀장에게(팀장이 켜져 있을 때만), 줄 하나, 일꾼 목록(색 점 + 이름, 고른 사람 표시). 자동·전체·팀장은 고르면 메뉴가 닫히고, 일꾼은 지금처럼 여러 명을 켜고 끌 수 있게 메뉴가 열려 있다.
- **인원**: `인원 [−] N명 [+]`. 지금의 에이전트 관리 −/+ 와 똑같이 동작한다(일하는 중인 마지막 클로드를 지울 때는 묻기, 1~8명).
- **⚙ 설정**: 누르면 지금 '모두에게' 줄의 네 칸(모델·깊이·속도·허락)이 든 작은 판이 열린다. 값이 바뀌는 방식은 지금과 같다(모든 에이전트 + 새로 늘릴 에이전트). 빠른 모드가 켜져 있으면 버튼에 ↯ 를 붙이고, 마우스를 올리면 네 값을 요약해 보여 준다.
- 화면이 좁으면 줄이 자연스럽게 다음 줄로 넘어간다. 메뉴는 기존 ⇄·대기 메뉴와 같은 방식(바깥 누르기·Esc 로 닫힘)을 쓴다.

## 정해 둔 것 (제 판단)
- 메뉴와 설정 판은 이미 있는 메뉴 도구(`placeMenu`/`closeMenus`)를 함께 쓴다.
- 새 글은 모두 `t()` 를 거치고 `locales/en.json` 에 영어를 넣는다.
- 확인: `npm test`(화면 id·핸들러 검사 포함) + 시험용 관제실을 화면에 띄워 보낼 곳 고르기·인원 늘리고 줄이기·설정 바꾸기를 직접 눌러 본다.

## 만들 사람이 정할 것
- 색·여백 같은 세세한 모양은 지금 프롬프트 칸의 칩·셀렉트 모양을 그대로 따른다.
