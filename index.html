    CCR에 있는 모델 · 눌러서 추가

    claude-code-router(CCR)를 거쳐 OpenRouter 같은 다른 AI가 일을 이어받아요. 무료 모델은 하루에 쓸 수 있는 횟수가 적고 Claude보다 실수가 많아요. 한도가 풀릴 시각이 지나면 다시 Claude가 맡아요. 처음 설정하는 방법은 도움말에 있어요.

    진단 정보는 문제가 생겨 도움을 구할 때 붙여 넣는 글이에요. 버전·설정·최근 오류만 담고, 시킨 일의 내용과 열쇠는 넣지 않아요.

    보안 기록

      허락·거절, 위험한 설정 바꾸기, 막은 일, 열쇠 없이 들어오려던 접근을 기록 폴더의 security.jsonl 에 남겨요. 시킨 일의 내용과 열쇠 값은 넣지 않아요.

      처음이라면 여기부터 읽어 보세요

      어떻게 돌아가나요?

      1. 에이전트 1명은 이 PC에서 따로 도는 Claude Code 1개예요. 최소 1명, 최대 8명까지 동시에 일해요.
      2. 프롬프트 창에 시킬 일을 적고 보낼 곳을 골라요. 자동 배정은 가장 한가한 에이전트에게, 전체는 모두에게 같은 일을 보내요.
      3. 작업 현황 창에서 에이전트들이 파일을 읽고 고치는 모습을 실시간으로 봐요. 칸마다 아래쪽 입력줄로 그 에이전트에게만 이어서 말할 수 있어요.
      4. 명령 실행처럼 조심해야 하는 일은 오른쪽 아래에 허락 요청이 떠요.

      허락 요청 고르기

      • 허락 — 이번 한 번만 해도 돼요.
      • 계속 허락 — 똑같은 명령은 이번 대화에서 다시 묻지 않아요.
      • 거절 — 하지 말라고 알려 줘요. 에이전트는 다른 방법을 찾아요.

        알아 두면 좋아요

        • 에이전트를 여러 명 돌리면 Claude 사용량도 그만큼 빨리 줄어요.
        • 프롬프트 창 아래 인원 −/+ 로 에이전트 수를, 설정에서 모든 에이전트의 모델·생각 깊이·속도·허락을 한꺼번에 바꿔요. 한 명만 바꾸려면 관리 창에서 바꿔요.
        • 속도: 빠르게 ↯는 Opus를 최대 2.5배 빠르게 돌리지만, 요금제 사용량이 아니라 유료 사용량 크레딧에서 따로 돈이 나가요. 크레딧을 켜 두지 않았으면 보통 속도로 돌아요.
        • 여러 에이전트가 같은 폴더에서 같은 파일을 고치면 서로 덮어쓸 수 있어요. 역할을 나누거나 폴더를 따로 주세요.
        • 에이전트는 대화를 기억해요. 전혀 다른 일을 시키려면 관리 창에서 새 대화를 누르세요.
        • 검은 서버 창을 닫으면 앱이 꺼져요. 설정과 기록은 기록 폴더(설정 창의 저장 위치)에 남아요.

        GPT 같이 쓰기 (OpenAI 공식 Codex)

        • 모델 칸에서 GPT 모델을 고르면 그 에이전트는 Codex로 일해요. 내 ChatGPT 로그인(무료 요금제 포함)을 쓰고, 따로 돈은 나가지 않아요.
        • GPT는 허락을 물을 수 없어서 작업 폴더 안에서만 파일을 고쳐요. 권한이 '계획만 세우기'나 '모두 물어보기'면 읽기만 해요.
        • 감독관 모델을 GPT로 고르면 만드는 건 Claude, 검사는 GPT로 나눠 일해요. 서로 다른 AI가 보면 놓치는 게 줄어요.
        • 에이전트의 AI가 바뀌면(Claude ↔ GPT ↔ 대체 AI) 새 AI에게 인수인계 쪽지를 먼저 건네요. 마지막으로 받은 일, 남긴 말, 고친 파일이 들어가요.
        • 작업 현황의 에이전트 칸에서 ⇄를 누르면 그 자리에서 다른 AI에게 넘겨요. 하던 일은 멈추고 새 AI가 이어서 하고, 오류로 막힌 마지막 일(예: Claude 사용량 한도)은 새 AI가 다시 해요.

        팀장과 검사 팀

        • 팀장 — 보낼 곳에서 팀장에게를 고르고 큰 일을 보내면, 팀장이 일꾼들에게 나눌 계획을 세워요. 계획을 보고 이대로 시작을 누르면 나눠 맡기고, 다 끝나면 결과를 모아 보고해요.
        • 감독관 → 보안 검사관 → 테스터 — 파일을 고치거나 명령을 실행한 일을 차례로 검사해요. 한 자리라도 고칠 점을 찾으면 그 일꾼이 고치고, 처음 자리부터 다시 봐요.
        • 테스터는 실제로 명령을 돌려 봐서 명령마다 허락을 물어요(GPT로 고르면 작업 폴더 안에서는 묻지 않아요). 보안 검사관은 코드에 적힌 열쇠나 위험한 명령을 찾아요.
        • 새 자리는 처음엔 꺼져 있어요. 켤수록 일 하나에 드는 AI 사용량이 늘어요. 에이전트 관리 창에서 켜고 꺼요.

        대체 AI 모드 (Claude 사용량이 바닥났을 때)

        1. 설정 창에서 CCR 설정 화면 열기를 눌러요. 브라우저에 claude-code-router 화면이 열려요.
        2. Providers에서 쓰고 싶은 AI를 모두 추가해요. 예) Codex(ChatGPT 로그인), Kimi, OpenRouter(내 키 + openrouter/free). 마지막 Connect agent 단계는 적용하지 말고 탭을 닫아요 — 적용하면 이 PC의 모든 Claude Code가 CCR로 가요.
        3. Server에서 Start를 누르고, 관제실 설정의 CCR 열쇠 옆 CCR에서 가져오기를 눌러요. (안 되면 CCR 화면 API Keys의 열쇠 값을 직접 붙여 넣어요.)
        4. 관제실 설정에서 대체 AI로 이어서 하기를 켜고 연결 확인을 누른 뒤, 쓸 순서에 모델을 눌러서 원하는 순서대로 넣어요.

        그다음부터는 Claude 한도에 걸리면 에이전트가 순서의 첫 AI로 바뀌어, 인수인계 쪽지를 받고 하던 일을 이어서 해요. 그 AI도 막히면 다음 AI로 넘어가고, 막혔던 AI는 15분 동안 건너뛰어요. 관리 창의 AI 연결에서 직접 바꿀 수도 있어요. 대체 AI와 나눈 대화는 Claude 대화와 따로 기억해요.
