# 클로드 관제실

창 하나에서 Claude Code 에이전트를 최대 8명까지 동시에 돌려요. 끝낸 일을 읽어 보고 고칠 점을 다시 시키는 감독관이 있고, 원하면 GPT(Codex) 에이전트와, Claude 사용량이 바닥났을 때 이어서 일하는 대체 AI도 쓸 수 있어요.

> **비공식 개인 프로젝트예요.** Anthropic이나 OpenAI가 만들거나 관계된 프로그램이 아니에요. 내가 직접 설치하고 로그인한 공식 `claude`(원하면 `codex`) 명령 도구를 움직이는 앱이에요.

[English](README.md)

## 할 수 있는 것

- **에이전트 1~8명을 동시에.** 에이전트마다 Claude Code가 하나씩 따로 돌아요. 가장 한가한 에이전트나 전체, 또는 고른 에이전트에게 일을 보내고, 파일을 읽고 고치는 모습을 실시간으로 봐요.
- **조심해야 하는 일은 내가 허락.** 명령 실행처럼 허락이 필요한 일은 허락·계속 허락·거절 카드로 떠요. 허락을 통째로 건너뛰는 모드는 일부러 넣지 않았어요.
- **감독관.** 파일을 고치거나 명령을 실행한 일을 읽기 전용 에이전트가 검토해서 짧게 보고하고, 고칠 점은 그 일꾼에게 다시 시켜요(1~3번까지).
- **GPT 에이전트 (선택).** 모델 칸에서 GPT를 고르면 그 에이전트는 내 ChatGPT 로그인으로 OpenAI 공식 Codex CLI에서 일해요. 허락을 물을 수 없어서 Codex 샌드박스 안에서 작업 폴더에만 쓸 수 있어요.
- **대체 AI (선택).** Claude 사용량 한도에 걸리면 [claude-code-router](https://github.com/musistudio/claude-code-router)를 거쳐 다른 AI(OpenRouter, Kimi, Codex 등)가 이어서 해요.
- **다른 AI에게 넘기기 (⇄).** 하던 일이나 오류로 막힌 일을 다른 AI에게 넘겨요. 새 AI는 인수인계 쪽지(마지막 일, 마지막 말, 고친 파일)를 먼저 받아서 처음부터 다시 하지 않고 이어서 해요.
- **한국어 / English 화면.** 처음 켤 때 고르고, 설정에서 바꿀 수 있어요.

## 필요한 것

- **Windows 10/11**에서 쓰려고 만들었어요. macOS·Linux에서도 `node server.js`로 켤 수는 있지만, 폴더 고르기 창은 윈도에서만 떠요(경로를 직접 적으면 돼요). `claude auth login`과 claude-code-router는 터미널에서 직접 켜야 해요.
- **Node.js 22.5 이상**을 권해요. 기본 기능은 Node 18 이상이면 되지만 "CCR에서 가져오기" 버튼은 22.5 이상이 필요해요. 의존성이 없어서 `npm install`은 할 필요 없어요.
- **Claude Code**(`claude`)를 설치하고 내 계정으로 로그인해 둬요. 에이전트는 내 Claude 요금제 사용량을 쓰니, 여러 명 돌리면 그만큼 빨리 줄어요.
- 선택: GPT 에이전트를 쓰려면 **OpenAI Codex**(Codex 앱 또는 `npm install -g @openai/codex`)를 설치하고 `codex login`으로 로그인해요.
- 선택: 대체 AI를 쓰려면 **claude-code-router**(`npm install -g @musistudio/claude-code-router`)를 설치해요. 쓸 AI는 그 프로그램 화면에서 넣되, **마지막 "Connect agent" 단계는 적용하지 마세요.** 적용하면 이 PC의 모든 Claude Code가 그쪽으로 가요.

## 시작하기

1. 이 폴더를 내려받거나 clone 해요.
2. 윈도에서는 **`실행.bat`**을 더블클릭해요. 다른 OS에서는 `node server.js`를 실행해요.
3. `http://127.0.0.1:7707`에 관제실이 열려요. 처음 켜면 언어, **작업 폴더**(에이전트가 파일을 만드는 곳), **기록 폴더**(설정·기록을 저장하는 곳)를 골라요.
4. Claude Code에 아직 로그인하지 않았다면 설정의 **로그인 창 열기**를 누르거나(윈도) `claude auth login`을 실행해요.

검은 서버 창을 닫으면 앱도 꺼져요.

## 어디에 저장되나요

| 무엇 | 어디 |
|---|---|
| 에이전트가 만드는 파일 | 작업 폴더 (기본 `workspace/`, 설정 → 저장 위치나 에이전트마다 바꿀 수 있어요) |
| 설정·기록·감독관 보고 | 기록 폴더 (기본 `data/`: `state.json`, `logs.json`) |
| 기록 폴더를 옮겼을 때 그 위치 | 앱 폴더의 `config.json` |
| 영어 번역 | `locales/en.json` |

기록 폴더에는 claude-code-router 열쇠가 그대로 적혀 있을 수 있으니 남에게 보여 주지 마세요. `data/`, `config.json`, 작업 폴더는 `.gitignore`에 들어 있어서 저장소에 올라가지 않아요.

## 실행 옵션

```
node server.js [--port 7707] [--no-open] [--data <폴더>] [--claude <경로>] [--codex <경로>]
```

- `--port` — 쓸 포트 (기본 7707)
- `--no-open` — 화면 창을 열지 않아요
- `--data` — 이 기록 폴더를 써요 (이 옵션을 쓰면 앱 안에서 기록 폴더를 바꿀 수 없어요)
- `--claude`, `--codex` — 특정 CLI를 써요 (가짜 CLI로 시험할 때도 써요)

## 보안

- 서버는 `127.0.0.1`에서만 열리고, 모든 API 요청에 켤 때마다 바뀌는 열쇠와 내 PC 주소(`Host`)가 있어야 해요. 그래서 다른 웹사이트가 에이전트를 조종할 수 없어요.
- 허락은 언제나 사용자가 하고, 감독관은 파일을 읽기만 해요.
- GPT 에이전트는 Codex 샌드박스에서 돌아요. 권한이 "계획만 세우기"나 "모두 물어보기"면 읽기만 하고, 나머지는 작업 폴더 안에서만 쓸 수 있어요.

## 비용

앱 자체는 무료이고 따로 서버가 없어요. 에이전트는 내 Claude 요금제 사용량을, GPT 에이전트는 내 ChatGPT 요금제의 Codex 사용량을, 대체 AI는 claude-code-router에 넣은 곳의 사용량을 써요. **빠른 모드(↯)**는 유료 사용량 크레딧에서 돈이 나가서, 기본으로 꺼져 있고 켤 때마다 물어봐요.

## 파일

- `server.js` — Node 서버 (의존성 없음). 에이전트마다 CLI를 하나씩 띄우고, 화면과는 Server-Sent Events로 이야기해요.
- `index.html` — 화면 전체.
- `locales/en.json` — 영어 번역. 코드에 적힌 한국어 문장이 열쇠예요.
- `실행.bat` / `로그인.bat` — 윈도용 실행·로그인 파일.
- `icon.ico` — 앱 아이콘.

## 번역

화면과 안내문의 모든 글은 `t('한국어 문장', { 값 })`을 거쳐요. 한국어 문장이 열쇠이고, `locales/en.json`이 그 문장을 영어로 바꿔 줘요(`{name}` 같은 자리 표시를 그대로 써요). 사전을 고친 뒤에는 서버를 다시 켜야 해요. 세 번째 언어를 더하려면 지금은 코드도 조금 고쳐야 해요(`server.js`의 `LANGS`·`DICTS`, `index.html`의 `LANG`, 언어 고르는 칸).

## 알아 둘 점

- 윈도 위주로 만들었고, macOS·Linux는 덜 시험했어요.
- Claude Code의 stream-json·허락 요청 방식에 기대고 있어서, CLI가 바뀌면 동작이 깨질 수 있어요.
- 코드 주석은 한국어로 적혀 있어요.
- Node.js 24, Claude Code 2.1, Codex CLI 0.166에서 시험했어요.
